# AI Learning Trust Lab Website

This is a static website for **AI Learning Trust Lab**, a student-led research and public education platform exploring how AI tutoring can support student thinking without replacing it.

## v2 update

This version adds an **About the Founder** section to the homepage.

## Files

- `index.html` — main landing page
- `styles.css` — site styling
- `briefs.html` — research brief topic page
- `rubric.html` — Trustworthy Explanation Rubric page
- `survey.html` — survey placeholder page
- `demo.html` — verifier demo placeholder page
- `reports.html` — mini reports placeholder page

## How to update on GitHub

1. Unzip this folder.
2. Open your GitHub repository.
3. Click **Add file → Upload files**.
4. Drag all files into the upload area.
5. Click **Commit changes**.
6. Wait 1–3 minutes for GitHub Pages to update.
